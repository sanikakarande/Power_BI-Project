# 📊 Sales Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance across different regions, products, and customer segments. The dashboard transforms raw sales data into meaningful insights through interactive visualizations, enabling data-driven business decisions.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Monitor key business KPIs
- Identify top-performing products and regions
- Track monthly sales and profit trends
- Support business decision-making using interactive dashboards

---

## 🛠️ Technologies Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV Dataset
- Data Modeling

---

## 📈 Dashboard Features

- Sales Performance Overview
- Profit Analysis
- Monthly Sales Trend
- Region-wise Sales Analysis
- Category & Sub-category Performance
- Top Selling Products
- Interactive Filters & Slicers
- KPI Cards for Quick Business Insights

---

## 📊 Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Sales
- Sales Growth (if applicable)

---

## 💡 Key Insights

- Identified the highest revenue-generating products and categories.
- Compared sales and profit across different regions.
- Analyzed monthly sales trends to identify seasonal patterns.
- Evaluated overall business performance using key performance indicators.
- Enabled quick business decisions through interactive dashboard visualizations.

---

## 🔄 Project Workflow

1. Imported the sales dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Created relationships between tables.
4. Developed DAX measures for KPI calculations.
5. Designed interactive reports and dashboards.
6. Generated business insights through visual analysis.
